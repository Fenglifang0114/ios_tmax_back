## Tmax通讯协议

#### 一、命令格式

| 名称   | 字节数 | 描述                                    | 备注 |
| ------ | ------ | --------------------------------------- | ---- |
| 包头   | 2      | 0x5A 0xA5                               |      |
| 长度   | 2      | 不含包头（总长度包含长度和包尾）        |      |
| 命令ID | 1      |                                         |      |
| 子类型 | 1      |                                         |      |
| 序号   | 1      | 命令序号                                | 保留 |
| 数据   | n      | 操作存储介质时，包含地址4、长度2、数据n |      |
| CRC    | 4      | 除头尾以外的所有数据                    |      |
| 包尾   | 2      | 0xA5 0x5A                               |      |

#### 二、0X05命令描述

0X05请求命令

| 命令ID | 子类型 | 描述                       | 备注 |
| ------ | ------ | -------------------------- | ---- |
| 0X05   | 0XF0   | 返回机种型号               |      |
|        | 0XF1   | 打开工厂模式               |      |
|        | 0XF2   | 关闭工厂模式               |      |
|        | 0XF3   | 打开透传模式               |      |
|        | 0XF4   | 关闭透传模式               |      |
|        | 0XF5   | 获取秤子可接收的最大包长度 |      |

#### 三、0XF1命令描述

0XF1存储介质操作

| 命令ID | 子类型 | 描述       | 备注 |
| ------ | ------ | ---------- | ---- |
| 0XF1   | 0X01   | 读flash    |      |
|        | 0X02   | 写flash    |      |
|        | 0X03   | 擦除flash  |      |
|        | 0X04   | 读eeprom   |      |
|        | 0X05   | 写eeprom   |      |
|        | 0X06   | 擦除eeprom |      |
|        | 0X07   | 读rom      |      |
|        | 0X08   | 写rom      |      |
|        | 0X09   | 擦除rom    |      |

当使用0XF1命令时，数据里划分出需要操作的地址、长度、数据

| 名称 | 字节数 | 描述                   | 备注 |
| ---- | ------ | ---------------------- | ---- |
| 数据 | 4      | 需要读写擦除地址       |      |
| 数据 | 2      | 需要读写擦除的数据长度 |      |
| 数据 | n      | 需要写的数据           |      |



#### 四、0XF2命令描述

0XF2透传命令

| 命令ID | 子类型 | 描述                 | 备注 |
| ------ | ------ | -------------------- | ---- |
| 0XF2   | 0X01   | 发送透传数据到BT     |      |
|        | 0X02   | 发送透传数据到WIFI   |      |
|        | 0X03   | 发送透传数据到打印机 |      |

|        | 0X07   | 开启连续发送 |      |
|        | 0X08   | 关闭连续发送 |      |
|        | 0X09   | 设置第一量程 |      |
|        | 0X0A   | 设置第二量程 |      |

#### 六、秤子回应
